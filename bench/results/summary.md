# 計測結果: アセットキャッシュ + GPUリソース用アロケータ

- 計測日: 2026-10-26 / ブランチ: allocatorMeasure / Release x64
- 環境: Core i7-11370H, RTX 3050 Laptop (4GB), RAM 16GB, AC電源, 1280x720 ウィンドウ
- 方法: `bench/run_bench.ps1 -Runs 11`(段階1→2→3を交互に11巡)。run=0 はコールドとして別表、平均は run=1〜10
- 段階の切り替えは MeshComponent のみ(Sprite/Text/FireParticle/DamageText は全段階で現行アロケータ)
- 段階1は N=1000 でテクスチャが VRAM 4GB を超えるため、D は N=100 のみ
